Politica de privacidad de Tepado
Última actualización: 6 de Octubre de 2026

En Tepado (en adelante, "la Aplicación"), valoramos y respetamos profundamente la privacidad de nuestros usuarios. Esta Política de Privacidad explica cómo se maneja la información en nuestra aplicación móvil, diseñada bajo estrictos principios de funcionamiento local y bajo consumo.
1. No recolección de datos personalesTepado NO recopila, almacena, transmite ni procesa ningún tipo de información personal identificable (como nombres, correos electrónicos, números de teléfono, ubicación geográfica ni listas de contactos). La Aplicación está diseñada para funcionar sin necesidad de registro ni creación de cuentas de usuario. No utilizamos sistemas de analíticas de terceros para rastrear tu comportamiento.
2. Procesamiento 100% local de archivos y documentosTodos los archivos que abres, importas o lees dentro de la Aplicación (archivos .pdf y .txt) son procesados exclusivamente de manera local en la memoria de tu dispositivo móvil mediante bases de datos cifradas por el sistema operativo (Room/SQLite).La Aplicación NO sube, NO transmite y NO almacena tus documentos en ningún servidor externo ni en la nube.
3. Uso de Funciones del Dispositivo y PermisosTepado está diseñada bajo el principio de minimización de permisos. No solicitamos acceso intrusivo a tu cámara ni a tu galería completa de fotos:
Acceso a Archivos y Almacenamiento Interno: No solicitamos el permiso invasivo para "Leer o Administrar todos los archivos" de tu dispositivo. Utilizamos el selector de documentos seguro nativo de Android. Cuando seleccionas un PDF o TXT, la Aplicación genera una copia que se guarda exclusivamente dentro de su propia "bóveda" interna y privada, a la cual ninguna otra aplicación tiene acceso. Estos documentos nunca se suben a la nube, no se respaldan en servidores externos y permanecen 100% bajo tu control en el almacenamiento local.
Cámara (Escáner de Documentos): Al igual que con los archivos, no tenemos acceso directo al hardware de tu cámara. Utilizamos el servicio nativo de Google Play Services para abrir la cámara de forma segura. Todo el procesamiento de la imagen y la extracción del texto (OCR) se ejecuta de forma 100% Offline dentro del procesador de tu teléfono. Las imágenes capturadas no se envían a internet.
Servicio en Primer Plano (Audio en Segundo Plano): Requerido exclusivamente para la función "Modo Podcast" (Text-To-Speech). Esto permite que el sistema operativo lea el texto en voz alta de forma continua mientras la pantalla está apagada para ahorrar batería.
Notificaciones: Solicitamos permiso para enviar notificaciones con el único fin de mostrar el reproductor multimedia del "Modo Podcast". Esto te permite pausar o detener la lectura fácilmente desde la barra de estado de tu teléfono. No enviamos notificaciones de publicidad ni spam.
4. Servicios de Terceros y PublicidadPara mantener la aplicación gratuita para los usuarios que no poseen la versión Premium, utilizamos el siguiente servicio de confianza:
Google AdMob (Publicidad): Muestra anuncios publicitarios en la app. AdMob puede recopilar datos técnicos no identificables (como el modelo del dispositivo o identificadores de publicidad de Android) cuando el teléfono tiene conexión a Internet para mostrar anuncios relevantes, sujeto a las políticas de privacidad de Google.
5. Procesamiento de PagosLas transacciones monetarias para desbloquear la versión Premium sin anuncios se realizan de forma nativa y 100% segura a través del sistema oficial de pagos de Google (Google Play Billing). Nosotros no recopilamos, almacenamos ni tenemos acceso a tus datos bancarios ni números de tarjetas de crédito. Tu estado de compra se guarda localmente en tu dispositivo de forma anónima.
6. Cambios a esta Política de PrivacidadPodemos actualizar nuestra Política de Privacidad de vez en cuando. Cualquier cambio se reflejará en esta misma página con una nueva fecha de "Última actualización".
